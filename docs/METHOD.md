# 方法概览

ResponsibilityModel 要解决的完整问题是：在市场状态不断变化且股票表现高度异质的情况下，如何用统一的经济机制坐标，同时指导因子证据选择与跨股票信息传导。

## 四类机制责任

模型用四个非负条件权重描述一只股票当前的机制责任：

1. 共同延续：市场共同成分所对应的延续证据；
2. 共同反转：市场共同成分所对应的修正证据；
3. 个股延续：市场残差成分所对应的延续证据；
4. 个股反转：市场残差成分所对应的修正证据。

它们是预测责任，不是因果识别结果。

## CRFR

CRFR 综合市场状态、个股状态和规则证据，先估计每只股票的机制责任，再汇总为当日共识责任。共识责任用于修正因子门，使模型在不同市场状态下选择不同的 Alpha158 证据。

通俗地说，CRFR回答：“今天市场主要由哪些机制主导，因此哪些因子更值得看？”

## RRCA

在单股时序编码和基础截面编码后，RRCA分别按四类机制在股票横截面上形成上下文。每只目标股票再根据自己的责任结构选择接收这些机制上下文的比例。

通俗地说，RRCA回答：“这只股票当前应重点参考哪些受同类机制驱动的股票？”

## 统一逻辑

```text
责任识别 -> 共识因子筛选 -> 时序/截面证据编码
         -> 个股责任路由的跨股票聚合 -> 收益预测
```

同一责任坐标贯穿前端和后端，因此“看什么因子”和“参考哪些股票”不再由两套彼此独立的逻辑决定。
